# Store-Annual-Report-Analysis-
Excel-based data analysis project featuring sales performance, customer demographics, order trends and an interactive dashboard.
Store Annual Report – Data Analysis Project

📌 Project Overview

This project focuses on analyzing Vrinda Store's annual sales data using Microsoft Excel. The objective is to identify sales trends, customer purchasing behaviour, order patterns and customer demographics through data cleaning, analysis and dashboard visualization.

🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization

📊 Project Analysis

The dashboard includes the following analysis:

1. Order vs Sales: Monthly comparison of sales and order volume.
2. Store Report: Store performance analysis.
3. Men vs Women: Gender-based sales analysis.
4. Order Status: Analysis of different order statuses.
5. Top 5 States: Identification of top-performing states.
6. Age vs Gender: Customer demographic analysis.
7. Orders Chart: Visualization of order trends.

🔍 Project Workflow

- Imported raw sales data into Excel.
- Cleaned and transformed data .
- Created Pivot Tables for data analysis.
- Developed charts and visualizations.
- Created an interactive Excel dashboard to present insights.

🎯 Key Skills Demonstrated

- Data Cleaning and Transformation
- Exploratory Data Analysis
- Excel Functions and Pivot Tables
- Data Visualization
- Dashboard Development


💡 Project Objective

To transform raw sales data into meaningful business insights and develop practical data analysis skills using Microsoft Excel.
